# Предметная область

Данный продукт может быть полезен, когда вы разрабатываете и для организации работы команды, не важно какого размера - маленькой или большой, используете Github Projects. Данный продукт является расширением для github-cli (дальше просто gh) и предоставляет более быструю и удобную работу с Github Projects по средством того, что запускается и работает прямо из консоли, имеет удобный TUI интерфейс и позволяет совершать необходимые действия посредством шорткатов. Всё это позволяет время на лишние действия и сосредаточится на разработке.

# Формулировка проблемы

Если вы для организации работы в команде используете Github Projects, его использование иногда может замедлять: нужно открыть браузер, зайти на страницу своего проекта на гитхабе и кликая мышкой совершить нужное действие. Большая часть разработки происходит в IDE и консоли, не убирая рук с клавиатуры, и подобное действие может просто выбить из процесса. Данный проект исправляет эту проблему позволяя внести необходимые изменения в проект не убирая рук с клавиатуры.

# Целевая аудитория

Целевой аудиторией данного продукта являются разработчики работающие с Github Projects. Они могут быть как и админами, которые могут менять настройки проекта и добавлять новых кантрибьютеров, так и редакторами или читателями. Всё, чего они хотят, - это быстро взглянуть на проект на Github или внести в него изменения. Сейчас им для этого нужно тратить время на ненужные действия, но с этим проектом они смогут это сделать прямо из консоли, не тратя лишнее время.

# Анализ аналогов

## gh-projects

[gh-projects](https://github.com/github/gh-projects) уже встроен в gh и является CLI инструментом, который позволяет получать информацию о проектах и редактировать её, но в реальности работать с ним неудобно, его функционал очень ограничен, и проще всего просто запустить браузер, зайти на страницу своего проекта и совершить нужное действие, что замедляет.

## gh-dash

[gh-dash](https://github.com/dlvhdr/gh-dash) - это пользовательское решение для gh, которое позволяет ревьювать и редактировать пулреквесты, ишью и реагировать на входящие уведомления на Github прямо из терминала с TUI интерфейсом и клавиатурными сокращениями. Но работать с Github Projects в нём нельзя и редактировать и просматривать поля ишью предназначенные для Github Projects тоже.

Больше как таковых аналогов моему проекту нет.

# Методы исследования

- Информация о недостатках работы с Github Projects была получена в ходе моей личной работы с ним.
- Информация о недостатках gh-project как инструмента для работы с Github Projects через консоль была получена на личном опыте и анализе открытых источников.
- Информация о gh-dash была получена на личном опыте и анализе открытых источников.

# Первоначальные требования

## Функциональные

Приложение должно:
- Отображать проект в формате доски с заданиями (layout Board в Github Projects).
- Отображать информацию об issue: название, блокируется ли она, её labels, также как это выглядит в Github Projects.
- Отображать прогресс родительских issue в виде полоски прогресса как в Github Projects.
- Позволять листать и перемещать issue пользуясь клавиатурными сокращениями.
- Предоставлять возможность пользователю посмотреть клавиатурные сокращения на клавишу "?".

## Не функциональные

Приложение должно:
- Запускаться на дистрибутивах Linux базированных на Debian.
- Иметь TUI интерфейс и стабильно работать в консольном эмуляторе Wezterm без деффектов при изменении размеров окна консоли или разбиении экрана на части.
- Создавать временный токен для обрещения к Github API.

# Выводы предпроектного исследования

Ключевыми проблемами является то, что Github не предоставляет никакого инструмента для того, чтобы быстро и удобно работать с проектами прямо из консоли и у него нет никаких клавиатурных сокращений, чтобы ускорить с ним работу. Реализовать решение нужно именно в виде консольного TUI приложения потому, что оно лучше всего подходит для решения текущей проблемы, так как CLI интерфейс очень ограничен, а GUI интерфейс более сложен и требует инициализации нового окна и переключения на него, когда TUI работает прямо из консоли и по своей сути достаточно прост.
